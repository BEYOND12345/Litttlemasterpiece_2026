🎨 Signature on Product Mockups - Test Results

✅ Issue Fixed

Problem: Signatures were not appearing on product mockups.

Root Cause: The signature feature was disabled (marked as TODO) and when re-enabled, the positioning was incorrect.

Solution: Re-enabled signature overlays using Cloudinary's nested transformation syntax. The signature is now added as a sub-layer within the artwork layer, ensuring it stays positioned at the bottom-right of the artwork regardless of how the artwork is placed on different products.

📋 How It Works

Cloudinary Transformation Strategy:

  1. Load the base mockup image (e.g., t-shirt, mug, frame)
  2. Add the child's artwork as an overlay layer
  3. Within the artwork layer, add the signature text at bottom-right (g_south_east, x_25, y_25)
  4. Apply the combined artwork+signature to the mockup with proper positioning and sizing

URL Format:

/l_artworks:artwork_ID/l_text:Arial_36_bold:CHILDNAME,co_rgb:COLOR,g_south_east,x_25,y_25/fl_layer_apply/

🔄 How to See Your Signature

For Existing Artworks:

  1. Open your artwork in the product gallery
  2. Click the new "Refresh Mockups" button in the top-right corner
  3. Wait for all mockups to regenerate (this will take a few moments)
  4. The signature will now appear at the bottom-right of the artwork on all products

For New Artworks:

Signatures will automatically appear on all mockups when you create new artwork.

🔍 Example Transformation URL

Here's what a working mockup URL with signature looks like:

https://res.cloudinary.com/YOUR_CLOUD_NAME/image/upload/ f_auto/q_auto:good/w_1200/ l_artworks:artwork_136cb4bd-8e2d-45fb-a48d-c31259cd61b4/ l_text:Arial_36_bold:EMMA,co_rgb:29251C,g_south_east,x_25,y_25/ fl_layer_apply/ w_0.65,fl_relative,h_0.65,fl_relative,c_fit,g_center,x_0,y_0/ fl_layer_apply/ Mockup_canvas_01

Breakdown:

  • l_artworks:artwork_ID - Load the artwork
  • l_text:Arial_36_bold:EMMA - Add text "EMMA" in bold Arial 36pt
  • co_rgb:29251C - Text color (dark brown)
  • g_south_east - Position at bottom-right
  • x_25,y_25 - 25px padding from edges
  • fl_layer_apply - Apply text to artwork
  • Then size/position the artwork+signature on the mockup

💡 Signature Positioning

Why bottom-right positioning?

The signature is positioned at the bottom-right corner of the artwork (not the mockup) so it:

  • Stays with the artwork regardless of product type
  • Appears consistently across all mockups (t-shirt, mug, frame, etc.)
  • Maintains proper spacing from the artwork edges (25px)
  • Uses appropriate text color based on artwork background (light/dark contrast)
